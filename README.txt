번역 개선 내용
- 영어 단어를 개별 치환하던 기존 방식을 제거했습니다.
- 효과 문장을 문장 구조와 효과 유형에 따라 한국어 어순으로 재구성합니다.
- PoEDB 한국어 아틀라스 용어와 문구를 기준으로 번역 사전을 보완했습니다.
- 노드 이름 400종과 효과/선택지 문자열 662종을 검사했습니다.
- 검사 결과, 노드 이름과 효과 문구에 영어 문장이 남지 않도록 처리했습니다.

주의
- PoEDB의 한국어 표기와 일치하도록 정리했지만, 모든 문장이 PoEDB 원문을 1:1로 복사한 것은 아닙니다.
- PoEDB에서 직접 대응시키기 어려운 문구는 게임 의미를 유지하도록 별도 번역했습니다. 특히 일부 고유명사와 신규 콘텐츠 용어는 실제 게임 내 표기와 추가 대조가 필요할 수 있습니다.
